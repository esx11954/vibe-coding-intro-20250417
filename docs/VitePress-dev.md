# Gemini CLIで構築するVitePress制作ガイド

Gemini CLIを使用して簡単にVitePressを構築するための手順書です。

## 1. VitePressプロジェクト作成プロンプト
プロジェクトのベースとなるサイトの土台を作成するためのプロンプトです。

> "必要なパッケージをインストールし、VitePressプロジェクト環境を初期化してください。"

## 2. ページを作成するプロンプト
Webサイトに情報を追加するためのプロンプトです。今回は「エイトビット株式会社」をテーマにします。

> "VitePressプロジェクトに「エイトビット株式会社」の概要を紹介する新しいページを作成してください。ページには、会社の概要やビジョンが伝わるように見出しを使い、読者が読みやすい構成で記述してください。"

## 3. 動作検証を行うプロンプト
作成したページをローカル環境で確認するためのプロンプトです。

> "作成したページをローカル環境で確認するための開発用サーバを起動するコマンドを実行して下さい。また、ブラウザで表示するためのURLを教えてください。"

## 4. VitePressのカスタマイズ項目
Webサイトは、以下の項目をカスタマイズすることで自分好みに変更可能です。
自分なりのプロンプトで好きにカスタマイズしてみましょう。

- **サイトのロゴやタイトル**: サイトの顔となる部分の変更
- **メニュー（ナビゲーションバー）**: ページのリンク先や構成の整理
- **サイドバー**: ページ内の情報を分類して表示する枠の設定
- **テーマカラー**: サイト全体の雰囲気を決める色の変更
- **フッター**: サイト下部に表示するコピーライトや関連リンクの追加
- **カスタムCSS**: デザインを細かく調整するためのスタイル設定
